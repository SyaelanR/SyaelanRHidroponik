# 🌿 HydroWatch: IoT-Powered Real-Time Hydroponic Monitoring

> Optimalkan pertumbuhan tanaman hidroponik Anda dengan sistem pemantauan berbasis IoT secara real-time. Pantau kondisi lingkungan kapan saja, lengkap dengan log data sensor yang akurat.

---

## ✨ Fitur Utama
* ⏱️ **Real-Time Monitoring:** Pantau suhu, pH, PPM air, dan cuaca secara instan tanpa delay.
* 📊 **Automated Data Logging:** Semua riwayat sensor tersimpan rapi untuk analisis pertumbuhan.
* 📱 **Responsive Dashboard:** Akses pemantauan dengan mudah lewat HP, tablet, maupun PC.

---

## 🛠️ Teknologi yang Digunakan

* **Framework**: NextJS
* **Database**: Postgresql
* **Frontend**: Tailwind CSS
* **Realtime**: WebSocket

---

## ⚙️ Instalasi

1. Clone repository

```bash
git clone https://github.com/SyaelanR/SyaelanRHidroponik
```

2. Masuk ke folder project

```bash
cd SyaelanRHidroponik
```

3. Install dependency

```bash
npm install && npm run build
```

4. Copy file environment Example

```bash
DATABASE_URL=""

API_KEY=

# MQTT
NEXT_PUBLIC_BROKER_URL=
NEXT_PUBLIC_BROKER_USERNAME=
NEXT_PUBLIC_BROKER_PASSWORD=
```

5. Konfigurasi database di file `.env`

6. Jalankan Server

```bash
npm run dev
```
